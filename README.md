小满家账：一款温暖的家庭预算账本网站。总览仪表盘看本月收支与结余、分类预算带超支提醒、流水可筛选搜索、Canvas 手绘统计图、储蓄目标一点点攒、家庭成员花销一目了然。数据只存在浏览器本地，静态文件零网络请求，桌面和手机都能用。

## Run it

```sh
node serve.ts
```

然后打开 http://localhost:8080
